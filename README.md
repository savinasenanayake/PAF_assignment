# Smart Campus Operations Hub – Module A

## Features
- Manage resources (lecture halls, labs, equipment)
- CRUD operations (Create, Read, Update, Delete)
- Filtering by type, capacity, location

## Tech Stack
- Backend: Spring Boot + MongoDB
- Frontend: React + Axios

## How to Run

### Backend
cd backend
./mvnw spring-boot:run

### Frontend
cd frontend
npm install
npm start

## API Endpoints
- POST /api/resources
- GET /api/resources
- GET /api/resources/{id}
- PUT /api/resources/{id}
- DELETE /api/resources/{id}
- GET /api/resources/filter
